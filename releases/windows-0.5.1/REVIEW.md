# 独立核验与处理

两名只读探子分别审查更新恢复链路、内部过滤与 UI／打包；主代理核实关键位置并负责修改与最终测试。

1. 通过：正式 Windows 标签、官方附件 URL、唯一 x64 ZIP 筛选。
2. 通过：下载长度及 SHA-256 校验；危险路径、重复大小写路径和链接拒绝。
3. 通过：staging 完整准备后才交换目录，旧版先备份，额外用户文件保留。
4. 通过：以进程句柄和完整 EXE 路径确定原进程，不按进程名结束其他副本。
5. 通过：权限气泡优先于更新气泡，权限与拖动延后重启。
6. 通过：构建 overlay 包含全部新增模块与测试，排除开发 bytecode。
7. 修复：权限到来时边缘隐藏窗口主动唤回；数据库轮换时 stat 异常纳入捕获。
8. 补强：目录交换记录、重命名重试、RunOnce 恢复入口及中断交换回归测试。
9. 明确边界：固定提示词前缀过滤保留随包兼容性；原样引用模板的未登记聊天有误判边界。
10. 保留策略：旧版备份保留供回退，不自动删除用户的历史备份。


> 本报告记录发布前的本地验证。正式 Windows 0.5.1 附件与最新校验值见对应 GitHub Release。
