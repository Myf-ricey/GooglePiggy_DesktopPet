## 已完成

- 启动后台检查一次，右键手动检查；只选择正式 Windows 版本，检查失败与最新版分开显示，重复检查合并。
- 粉色更新气泡、逆时针 30° 暖黄色灯泡、浮动／呼吸效果；Windows 动画关闭时静止；权限优先、下载进度、取消及重试。
- GitHub HTTPS 元数据与附件 SHA-256 校验、包内版本及逐文件校验，拒绝损坏、跨平台和不安全 ZIP。
- 独立 helper 等待精确的原进程退出，完整备份后原路径替换；启动健康检查失败恢复旧版。目录交换写恢复记录，正式更新注册临时 RunOnce 恢复入口，正常完成后移除。
- 自启动和 Hook 注册路径保持，用户额外配置保留；更新不会重新运行安装器或修改 Codex 信任数据。
- 下一句建议、首页推荐、Claudian 标题、专用目录中的 Memory Writing Agent Phase 2 过滤。补充 CRLF、长标题、真实子代理保护、数据库轮换异常处理。
- 隐藏在屏幕边缘时，权限请求能够唤回桌宠。

## 实测边界与发布准备

- 本机物理显示为 150% 单屏；100/125/200% 与多屏负坐标通过渲染／几何测试，尚未在相应物理显示器上验证。
- RunOnce 恢复入口已实现；中断目录交换的恢复函数已测，未进行真实断电或注销重登破坏性测试。
- Windows 使用 GitHub HTTPS + SHA-256 信任模型，尚未加入发布者独立数字签名，也未申请 Authenticode。Mac Sparkle 私钥未读取或导出。
- 四类过滤依赖固定标记／提示词与目录条件；未登记聊天原样粘贴内部模板仍存在误判边界，未承诺识别未来所有内部代理。
- 记忆测试全部使用合成数据，未开启或触发用户账号的 memories。
- GitHub 上传、远程 CI、公开升级下载链路仍待用户决定发布后验证。0.4.2 用户首次升级需要手动安装。
- 完整备份保留在安装目录同级 `.backup-…`，恢复材料在状态目录 `updates` 中；确认稳定后可手动清理旧备份。
