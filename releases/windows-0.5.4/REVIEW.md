# Windows 0.5.4 范围审查

基准：已发布 v0.5.3-windows（9e50084c013380a8ed0d613265e82f574631fc88）。

## Standards

未发现阻断发布的问题。已核验后台队列只有一个在途批次、UI 独占任务状态写入、定时器关闭句柄并停止工作线程。独立审查提出的退出后短暂后台读取属于设计内行为：读取使用上下文管理器释放资源，daemon 不阻塞退出。PostMessageW 对无效 HWND 返回失败而非抛出异常；现有代码没有审查意见所假设的自动 OSError，原生退出回归通过。

发布使用新补丁号 0.5.4，不覆盖已发布的 0.5.3 标签或附件。内部构建号只用于定位构建，不承担升级排序。

## Spec

主线程逐项对照用户要求完成核验：只调整 Windows 共用播放/绘制/缓存，以及为消除主线程阻塞而必要的观察器 I/O 调度；增加对应测量、测试和发布文档。66 项回归通过。

状态机 family_store.py、休闲规则 leisure.py、IPC codex_bridge.py、Hooks、安装/卸载、windows_update.py 和 update_notice.py 与发布基准一致。观察器事件识别/过滤/日志解析、权限同步、更新界面处理及自启动方法 AST 相同。异步读取不直接修改 UI 状态；迟到结果与未确认事件重试已有测试。

Mac、工作流和素材通过提交树及包内容哈希保护。平台版本号、构建号、发布说明、打包清单的调整是本次发布所需元数据变更。
