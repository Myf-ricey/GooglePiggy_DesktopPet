# Windows 0.5.7 自启动修复验收

构建20261025.1-system-startup。用户已授权发布此自启动修复。

根因范围：原实现只检查进程内Run值存在性，保存偏好后跳过登记检查，写入不进行系统侧读回。隔离测试复现原函数返回成功、同进程认为已启用，而系统StdRegProv读不到新测试项。造成两个视图不一致的底层机制尚未确定，不归因于有人关闭、权限被拒绝或所有机器必现。

改动覆盖应用、安装器、卸载器及菜单错误处理。统一使用Windows StdRegProv当前用户SID登记、查询与读回；缺失/旧路径修复，保留主动关闭和系统禁用，目标存在性和260字符长度检查，查询失败显示未确认。旧目录卸载不会注销新安装。

七项独立系统测试通过：首次注册、丢失修复、旧路径修复、关闭偏好保留、系统禁用保留与显式启用、无效目标拒绝、Win32_StartupCommand独立识别启用/移除。测试进程不是管理员，没有UAC提权。

冻结EXE已加载并调用随包PowerShell后端。部署到本机原目录前备份0.5.6，故意移除系统Run项后启动新EXE，程序自动重建登记；独立系统启动列表确认唯一条目，路径正确、文件存在、偏好1、无系统禁用/策略阻止。外观与Hook保持不变。

尚未注销或重启电脑，注册验证不冒充实际登录启动验收。作为新Windows补丁发布，不覆盖已发布0.5.6。
